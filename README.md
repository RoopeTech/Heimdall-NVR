# Heimdall NVR - IP Camera Viewer & NVR Dashboard

A lightweight, high-performance, and feature-rich **Network Video Recorder (NVR)** and **IP Camera Viewer** designed as a web-accessible server. Any browser on your network — PC, phone, or tablet — can connect to the dashboard and view live feeds, recordings, and manage settings. Runs on **Windows**, **Linux**, and **macOS** (including headless server environments).

## 🚀 Key Features

- **Norse/Valhalla Theme**: A premium responsive dashboard styled with curated moody fjord backgrounds (`#0a0f12`), amber/gold accents (`#fbbf24`), and runic fonts for an epic aesthetic.
- **Lightweight Server/Client Architecture**: Runs as a headless Python (FastAPI/uvicorn) backend server. Any browser on your network — PC, phone, or tablet — can connect to the dashboard and view live feeds, recordings, and manage settings.
- **Zero-CPU Recording**: Leverages background `ffmpeg` with `-c copy` to record high-resolution camera streams. Instead of transcoding (which exhausts CPU), it copies raw H.264 streams directly into an MP4 container, maintaining native quality with near **0% CPU usage**. Audio is converted to AAC during recording so it plays natively in the browser.
- **Ultra-Low Latency WebRTC Streaming**: Powered by `go2rtc` for sub-second live video latency with full two-way audio (push-to-talk). A fallback MJPEG streaming engine is available for users who encounter WebRTC issues.
- **Two-Way Audio (Push to Talk)**: Hold a microphone button in the Camera Details pane to transmit audio to your camera's built-in speaker with sub-second latency over WebRTC.
- **Flexible NVR Recording Modes**:
    - **Motion Only**: Records clips only when motion is detected.
    - **Continuous (Always)**: Records continuously 24/7 in 15-minute segments. Skips motion analysis to save CPU.
    - **Hybrid**: Records continuously 24/7 and runs OpenCV motion detection in the background to log motion alert events.
    - **View Only**: Streams the camera live with zero disk writes.
- **Motion Webhooks**: Receive instant notifications via **Discord** or **Telegram** when motion is detected. Customize media attachments — include a picture, a short video clip, or both. Test your configurations directly from Settings.
- **Interactive 24-Hour Timeline**: Displays recordings as segments on a 24-hour visual playhead track. Scrubbing seeks the video player instantly to that second. Clicking empty space on the timeline snaps the playhead to the nearest preceding recording segment.
- **Gesture-Bound Zoom & Panning**:
    - **Desktop**: Use the mouse scroll wheel to digitally zoom (up to 8x) and click-and-drag to pan around the zoomed region.
    - **Mobile**: Supports fluid pinch-to-zoom and one-finger drag-to-pan touch gestures.
- **Stream Quality Profiles**: Switch between HD, SD, and Low JPEG profiles in the Camera Detail view for optimized remote viewing on poor cellular connections.
- **Theatre Mode**: Expand the live view or playback video to maximize screen real-estate, cleanly hiding the timeline and sidebars for focused monitoring.
- **BlueIris-Style NVR Montage**: A full-bleed CSS Grid mosaic for live viewing that maximizes screen real-estate. Mobile-optimized layout automatically preserves a 16:9 aspect ratio and prevents squishing via native scrolling.
- **Custom Camera Groups**: Group cameras into logical collections (e.g., "Front Yard", "Inside") and filter the live grid instantly. Settings are saved per-user so your favorite group is always loaded on launch.
- **Recordings Archive Tab**: A dedicated global dashboard to filter, search, and browse historical recordings by date and camera. The previous Event Log has been merged here for a seamless playback experience.
- **Stream Recovery**: Built-in "Restart Stream" controls to intuitively force-reconnect stuck or dropped RTSP camera feeds without needing to restart the backend NVR process.
- **Dual-Stream Pipeline**: Configure separate high-res (Main) and low-res (Sub) streams. The sub-stream powers the dashboard mosaic, motion detection, and OpenCV overlays, while the main stream is used for zero-CPU pristine disk recording and full-screen detailed previewing.
- **Camera OSD (On-Screen Display)**: Renders a high-contrast green name tag (`LIVE`) and white date & time timestamp on top of the live sub-stream using OpenCV. Features semi-transparent black backgrounds for readability on bright camera feeds.
- **PTZ Preset 1 Return-to-Home**: Connects PTZ cameras and maps a single "Return to Home" command across multiple protocols (ONVIF, Foscam, CamHi/Boavision).
- **Secure RTSP Credentials**: Plaintext credentials are automatically parsed, stripped from stream URL fields, and stored in dedicated secure database columns to prevent exposure in logs or UI forms.
- **Website / Iframe Widget**: Embed external websites or web apps directly in the camera grid via iframe support — useful for dashboards, weather cams, or other embedded content.
- **Role-Based Access Control (RBAC)**:
    - **Admin**: Has full access, including managing cameras, system titles, and user accounts.
    - **Viewer**: Read-only access to live streams, events logs, timeline playbacks, and PTZ controls (cannot modify settings).
- **User Accounts Manager**: Admins can add, update passwords, toggle roles, and delete user accounts. Secure password hashing uses PBKDF2-HMAC-SHA256 with 100,000 iterations and random salts.
- **Azure Entra SSO**: Import Federation Metadata XML for one-click OIDC configuration, enabling Azure AD / Entra ID authentication for the NVR dashboard.
- **Progressive Web App (PWA)**: Fully installable PWA for Android/iOS Chrome and desktop browsers. Features customized security camera launcher icons, custom manifest files, and a service worker configured with pass-through bypasses for live feeds and playback segments to prevent browser cache exhaustion.
- **Native Android App**: A fully native Android application built with **Jetpack Compose** and **Kotlin Coroutines** (located in `android-app/`). It provides a fast, full-screen mobile experience with instant API data fetching, WebRTC and MJPEG live streaming support, and comprehensive error handling. Download the latest `.apk` from the GitHub Releases page!
- **NAS Archiving & Storage Management**:
    - **Per-Camera Archiving**: Offload old recordings to a NAS share or secondary local disk automatically. Set a local retention time (e.g. 7 days), after which the background mover daemon securely copies the recording to the archive path. Archived videos play seamlessly in the timeline UI.
    - **Global Auto-Cleanup**: Configure a global deletion threshold to permanently prune expired recordings and delete their files from the disk (or NAS) to prevent infinite storage growth.
- **Encrypted Configuration Backup & Restore**: Download a single JSON backup of your cameras, system settings, and user accounts. Features optional **AES-256 encryption** with a passphrase to securely lock down your plaintext RTSP passwords within the backup file. Restore this backup file on another machine to migrate servers instantly.
- **In-App System Updates**: Automatically pulls updates from a dynamically configurable Git remote (defaults to GitHub). Customize the remote to self-host your own codebase (e.g. on Gitea). Uses standard Semantic Versioning (SemVer) and includes an integrated Changelog viewer in the Settings UI. Rebuilds the React frontend and restarts the backend server automatically.
- **Cross-Platform Auto-Installer**: Automated bootstrapping downloads the correct static `ffmpeg` and `go2rtc` binaries for Windows, Linux, and macOS on first launch — no manual dependencies required.
- **Camera Simulator**: Preconfigured out-of-the-box with a simulated indoor room, bouncing intruder target, and interactive PTZ responses. Test motion logging, timeline playback, and events instantly without connecting a physical camera.
- **Home Assistant Integration**: A custom component (`custom_components/heimdall_nvr/`) provides full Home Assistant support — live camera feeds, motion binary sensors, status sensors, and seamless device registry integration. Compatible with HACS.

## 🛠️ Setup & Installation

### 1. Clone the Repository

Before installing, clone the repository from GitHub and enter the project folder:

```bash
git clone https://github.com/RoopeTech/Heimdall-NVR.git
cd Heimdall-NVR
```

*(All installation and update commands must be run from inside this folder).*

### 2. Run the Automated Installer

The installer checks for system dependencies (Node.js, Python 3), creates a virtual environment, installs packages, and compiles the frontend assets.

#### Linux (Debian/Ubuntu/Fedora/Arch)

```bash
chmod +x install.sh
./install.sh
```

#### macOS

```bash
chmod +x install.sh
./install.sh
```

#### Windows

```powershell
.\install.ps1
```

## 🖥️ Running the Server

Start the backend server directly:

```bash
backend/venv/bin/python backend/main.py
```

The dashboard will be accessible from any device on your network at `http://<server-ip>:8000`.

### Running as a Background Daemon (Recommended)

To have the NVR start automatically on boot and run in the background:

1. Copy the provided Systemd service file:

   ```bash
   sudo cp nvr-headless.service /etc/systemd/system/Heimdall-nvr.service
   ```

2. Edit `/etc/systemd/system/Heimdall-nvr.service` to update your `User` and `WorkingDirectory` paths.

3. Enable and start the service:

   ```bash
   sudo systemctl daemon-reload
   sudo systemctl enable --now Heimdall-nvr.service
   ```

4. Verify logs with `sudo journalctl -u Heimdall-nvr.service -f`.

## 🏠 Home Assistant Integration

Heimdall NVR ships with a full **Home Assistant custom component** available via HACS or manual installation:

1. Copy the `custom_components/heimdall_nvr/` directory into your Home Assistant `config/custom_components/` folder.
2. Restart Home Assistant.
3. Go to **Settings → Devices & Services → Add Integration** and search for **Heimdall NVR**.
4. Enter your NVR server address and credentials.

The integration provides live camera feeds, motion binary sensors, and NVR status sensors. It registers a dedicated Hub device in the Home Assistant device registry. See `custom_components/heimdall_nvr/README.md` for details.

## ⚙️ Administration, Updates & Server Migration

To manage the NVR application, check for updates, or backup settings, navigate to the **System Settings** tab (accessible only by users with the **Admin** role):

1. **Auto-delete Old Recordings**: Set the global number of retention days (e.g. `14`). The background cleanup thread will run hourly and remove old files from disk. Set to `0` to keep recordings forever.
2. **NAS Archiving (Per-Camera)**: Edit a camera's settings to set an `Archive Days` threshold and `Archive Path`. Files older than this will be moved automatically to secondary storage while remaining fully playable in the Activity Log.
3. **Export Config File**: Click the button to download a `.json` backup containing all configured cameras, system title, and user accounts. You can optionally provide a passphrase to AES encrypt camera passwords within the file.
4. **Import Config File**: Upload the `.json` file on a new server to restore your complete NVR configuration instantly (prompts for decryption password if encrypted).
5. **System Updates Manager**: Check local versus remote git commit hashes. If a newer version is available, click **Apply System Update** to perform a git pull, recompile UI static files, and hot-restart the NVR daemon process. The integrated Changelog viewer shows release notes for each version.
6. **Webhook Configuration**: Set up Discord or Telegram webhooks to receive motion alerts with attached photos and video clips.
7. **Streaming Engine Toggle**: Switch between WebRTC (low latency, audio enabled) and legacy MJPEG streaming.
8. **Azure SSO Settings**: Configure OIDC authentication via Azure Entra ID / Federation Metadata import.

## 🔒 Security Best Practices

- **Default Credentials**: Seeding a new database creates a default administrator account. A warning banner will display on the interface until the password is changed. Change this immediately using the profile menu dropdown in the top-right header.
- **Header Authorization**: All media streaming (/live and playback) and API endpoints are protected.
- **SSO Support**: Azure Entra SSO provides enterprise-grade authentication for the dashboard.
